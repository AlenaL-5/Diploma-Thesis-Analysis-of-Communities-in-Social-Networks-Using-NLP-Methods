# Diploma-Thesis-Analysis-of-Communities-in-Social-Networks-Using-NLP-Methods
Это мой дипломный проект. Он представляет собой программно-алгоритмический комплекс для анализа сообщества в социальных сетях с использованием методов обработки естественного языка (NLP). Основная задача данного проекта выявление неявных связей между пользователями в социальных сетях, в данном случае “ВКонтакте”. Связь между людьми в них может быть явной, например в виде подписки, или неявной, в виде похожего контента, например – схожих текстов постов. Попадание в целевую аудиторию будет более точным если при анализе использовать такие неявные связи.   Анализ сообществ проводится государственными и негосударственными службами для обеспечения безопасности, маркетологами, в частности таргетологами, для которых проект будет наиболее полезен. Система берет информацию из социальной сети, находит явные связи, при помощи методов NLP выявляет неявные связи, представляет полученные данные в виде графа и выделяет в нем скрытые сообщества с помощью методов кластеризации графа.

Блокнот collection of initial data.ipynb осуществляет сбор необходимых для анализа данных из социальной сети, начиная с нахождения идентификаторов пользователей по общему признаку, в данном случае была выбрана геопозиция. Сначала вводится город для поиска, затем ищутся идентификаторы пользователей из этого города. После того, как были найдены идентификаторы они разделяются на пакеты, представленные списком идентификаторов. Каждый такой пакет сначала проходит через функцию определения открытых и незаблокированных страниц пользователей, а потом через функцию сбора текстов постов и идентификаторов подписчиков. Дальше из получившегося списка пользователей и их подписчиков находятся подписчики из города. В результате выполнения блокнота получаются файлы: 

* подписки пользователей из города на друг друга.xlsx,  
* пользователи из города.xlsx.

Блокнот comparison_of_post_texts.ipynb сравнивает полученные в результате работы collection of initial data.ipynb тексты постов. Процесс сравнения заключается в вычислении косинусного расстояния между векторным представлением текстов. Текст постов сначала разделяется на предложения. Каждое предложение разделяется на слова и переводится в нижний регистр. Каждое слово проверяется, не является ли оно стоп-словом или числом. В список стоп-слов входят: слова из nltk.stopwords.words('russian'); знаки препинания из punctuation, библиотеки string; символы и слова: \`, .., ", ..., », «, \`\`, '', это, который, ещё, \|https, либо, всё, весь, свой. Если слово не входит в список-стоп слов и не является числом, то оно приводится в нормальную форму и добавляется в список слов предложения. Дальше идет проверка размера получившегося предложения. Если в предложении больше 5 слов, объединяем слова в строку, разделяя их пробелами, добавляем получившуюся строку в список получившихся предложений текста. После того, как будут проверены все предложения они объединяются в строку. Строка, полученная после предобработки текста, преобразуется в тензоры. **Для векторизации используется модель sbert\_large\_nlu\_ru.** Чтобы получить вектор текста вектора, представленные результатом последнего скрытого слоя («last\_hidden\_state»), агрегируются. После того, как был векторизован текст постов пользователя, проверяется его связь с другими пользователями. Для каждого пользователя, если он не текущий пользователь, ещё не рассматривался в сравнении с текущим и не связан подпиской с текущим, то записываем в строку тексты постов этого сравниваемого пользователя (с кем текущий пользователь неявно связан), вносим идентификатор текущего пользователя в список идентификаторов текущего пользователя и в отдельный список текст его постов. Функция сравнения возвращает косинусное расстояние, добавляемое затем в DataFrame с результатами сравнения. После этого проверяется, что косинусное расстояние больше 0,80. Сравнение удаляется, если условие не выполняется. В результате выполнения блокнота получаются файлы: 

* Граф со связью подпиской.png,  
* ребра итогового графа с весами.xlsx,  
* результат сравнения.xlsx,   
* Получившийся после сравнения граф.png.

Блокнот application_of_clustering_algorithms.ipynb применяет алгоритмы кластеризации графов на получившихся в результате выполнения comparison\_of\_post\_texts.ipynb данных. Как как неявная связь показывает сходство текстов двух пользователей, то тексты одного пользователя похожи на тексты другого и наоборот, тексты другого похожи на тексты первого. Таким образом, можно предположить, что первый пользователь связан со вторым и второй пользователь связан с первым. На ориентированном графе это можно изобразить двумя дугами с одинаковыми весами, имеющими противоположные направления, между двумя вершинами. В получившимся графе с добавленными неявными связями есть множество изолированных вершин. При применении алгоритма кластеризации они будут давать шум, в виде множества кластеров, состоящих только из одной вершины. Для предотвращения этого создается новый граф, состоящий только из вершин, которые связаны и этих самых связей. В получившемся графе выделяются лидеры по степени вершин. Чтобы выделить неявные сообщества реализованы 6 алгоритмов кластеризации: алгоритм распространения метки, алгоритм на основе выделения компонент сильной связности, алгоритм подсчета числа треугольников, алгоритм Гирвана-Ньюмана, алгоритм Лейдена, алгоритм Лувена. Алгоритм Гирвана-Ньюмана был реализован двумя способами: с помощью библиотеки igraph и библиотеки networkx. Алгоритм Лувена также был реализован двумя способами: с помощью networkx и leidenalg Полученные в результате выполнения блокнота файлы: 

* Граф только со связанными вершинами.png,  
* Кластеризация алгоритмом распространения метки.png,   
* Кластеризация на основе выделения компонент связности.png,   
* Кластеризация подсчетом числа треугольников.png,   
* Гирван-Ньюман igraph.png,   
* Гирван-Ньюман networkx.png,   
* Лейден leidenalg.png,   
* Лувен leidenalg.png,   
* Лувен networkx.png,
* результаты применения различных методов кластеризации.xlsx.

**Все блокноты запускаются вручную последовательно, сначала collection of initial data, затем comparison\_of\_post\_texts, а после application\_of\_clustering\_algorithms.**
